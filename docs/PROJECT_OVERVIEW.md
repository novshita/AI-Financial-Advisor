# Project Overview

## Title
AI Financial Advisor: A Multi-Agent Intelligent Personal Finance Planning System

## Problem Statement
Many users find it difficult to understand their income, spending, debt, savings and financial goals together. The project demonstrates how multiple AI-style agents can divide the problem into specialized tasks and combine the results into one understandable financial plan.

## Objectives
1. Analyze a user's financial profile.
2. Identify budget strengths and risks.
3. Calculate goal-based savings requirements.
4. Explain investment categories according to risk preference.
5. Calculate basic financial metrics.
6. Coordinate multiple agents into a final report.

## Modules
Profile Agent → Budget Agent → Goal Agent → Investment Agent → Calculation Agent → Coordinator

## Expected Output
The dashboard displays financial health, monthly surplus, savings rate, goal requirement, budget warnings, investment education and a combined coordinator report.
