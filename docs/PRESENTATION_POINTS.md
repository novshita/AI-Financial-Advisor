# PPT / Viva Points

## Slide 1 — Title
AI Financial Advisor: Multi-Agent Personal Finance Planning System

## Slide 2 — Problem
Users often have income, expenses, debt and goals but no single simple tool that analyzes them together.

## Slide 3 — Proposed Solution
A Streamlit dashboard where specialized agents analyze different financial aspects and a coordinator combines their outputs.

## Slide 4 — Agents
- Profile Agent
- Budget Agent
- Goal Agent
- Investment Education Agent
- Calculation Agent
- Coordinator Agent

## Slide 5 — Technology
Python, Streamlit, Pandas, NumPy, rule-based agent workflow; optional future LLM integration.

## Slide 6 — Workflow
User Input → Profile → Budget/Goal/Investment/Calculations → Coordinator → Financial Plan

## Slide 7 — Key Features
Financial health score, surplus calculation, goal planner, EMI calculator, risk-based educational guidance.

## Slide 8 — Future Scope
LLM integration, CSV expense analysis, SQLite, authentication, live trusted data and PDF reports.

## Slide 9 — Limitations
The demo uses simplified formulas and does not provide regulated investment advice.

## Slide 10 — Conclusion
The project demonstrates how agentic AI architecture can break a complex financial-planning task into smaller specialized tasks and combine them into a useful result.
