# 3-Minute Demo Script

1. Start the app with `streamlit run app.py`.
2. Enter income, expenses, savings, EMI, goal, timeline and risk preference.
3. Show the Financial Health Score.
4. Open Budget Agent and explain its warnings.
5. Open Goal Agent and show the required monthly saving.
6. Open Investment Agent and explain that it provides educational categories rather than guaranteed recommendations.
7. Open Calculations and demonstrate the EMI calculator.
8. Click Analyze My Finances.
9. Explain that the coordinator combines outputs from all specialized agents.
10. End by explaining future LLM integration.
